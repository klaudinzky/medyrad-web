name: Remote editorial changes
description: Protect independently published CMS edits when working from this workspace.

Fetch and reconcile GitHub changes before modifying editorial content.

**Why:** The site's CMS publishes through GitHub independently of the workspace. The user explicitly requires preserving those remote editorial changes.

**How to apply:** Check remote divergence before edits and again before pushing deployment changes; integrate new editorial commits instead of overwriting them or force-pushing.
